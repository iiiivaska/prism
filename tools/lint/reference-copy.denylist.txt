# Reference UI copy denylist for tools/lint/reference-copy.ts (ADR-0015 rules 1-3, critic R-01,
# visual-dna B26).
#
# Derived from docs/research/refs-*.md. Each entry is a string that those analyses quote from a
# reference shot's screen (a title, label, metric name, sample value, id or place name), or a studio,
# client or third-party brand name that ADR-0015 rule 2 keeps out of samples. The repository is
# public, and ADR-0015 admits the references only as URLs plus analysis in Prism's own words, so this
# copy must never reach contracts, samples or renders. The guard fails CI when an entry appears in
# spec/, tokens/, brands/, agent/, web/packages/*/src, web/apps/* (build output excluded),
# swift/Sources, swift/Tests, gallery/ or docs/research/fonts/. Generic words ("Today", "Settings",
# "Search", "Online"), bare numbers and bare units are left out on purpose: they are not recognizable
# copy and would only produce false positives.
#
# Format: one string per line; blank lines and lines that start with "#" are ignored. Matching is
# case-insensitive. Any run of spaces in an entry also matches no space or a line break, so
# "± 2.5 min" catches "±2.5min" and HTML text split by tags ("Credit Karma" also catches
# "creditkarma"). ' and ’ match each other. Backslash escapes are decoded ("\u00b1" is "±"), and
# Markdown emphasis does not split an entry ("**Credit** Karma"). An entry that starts or ends with a
# letter or digit only matches at a word edge ("Soma" does not match "somatic"), so a quote that the
# screen truncates is listed as quoted and, when the rest of the word is evident, completed too.
# Entries need at least four characters. Add an entry only after finding its source line in a refs
# analysis, and never copy an entry into a sample, test or fixture: the guard's tests use an invented
# list.
