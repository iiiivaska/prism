# DTCG 2025.10 JSON Schemas: license

`format.json` and `resolver.json` in this folder are unmodified, byte-identical copies of the JSON Schemas of the Design Tokens Community Group for the Design Tokens Format Module 2025.10 and the Design Tokens Resolver Module 2025.10, as published at:

- https://www.designtokens.org/schemas/2025.10/format.json
- https://www.designtokens.org/schemas/2025.10/resolver.json

They come from the `schemas/` package of https://github.com/design-tokens/community-group (`@dtcg/schemas`). `SHA256SUMS` pins their bytes, and `tools/tokens/validate.ts` refuses to run when a file differs from it (ADR-0024 §10). Prism made no changes to them.
