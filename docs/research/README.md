# Research

Inputs the blueprint was built from. Dated 2026-09-08 unless noted. Facts carry source URLs; opinions are marked as such.

| File | What |
|------|------|
| `visual-dna.md` | Synthesis of the reference analysis: principles with numbers, two mood presets, reference-brand palette proposal, signature moves, anti-patterns |
| `refs-*.md` | Forensic analysis per reference product family (RonDesignLab shots: Vexto traffic and incident, Soma, Hydroflask, Credit Karma, CreditPros, Arvion) |
| `component-inventory.md` | Every component observed in the references mapped onto the five layers |
| `a11y-reconciliation.md` | Contrast audit of the proposed palettes with compliant substitutes. It gives the `pnpm contrast:check` result per brand and scheme and reconciles it with the seeded values (visual-dna §3.7 and Appendix A), the P1-1 and P1-2 token changes, and the substitutes chosen by ADR-0021 and ADR-0022. Dated 2026-09-15, generated from the tool's output |
| `arch-tokens.md` | DTCG spec status, Style Dictionary / Terrazzo facts, token architectures of Material 3, Spectrum, Polaris, Atlassian, Primer |
| `arch-web.md` | React headless primitives, Tailwind v4, chart libraries, gallery and visual regression, publishing |
| `arch-apple.md` | Liquid Glass APIs, accessibility environment, Swift Charts, SPM constraints, fonts and symbols on Apple |
| `icons-tooling.md` | Phosphor, SF Symbols 7/8 and licenses, competitor sets, registry design, chart curve parity |
| `fonts.md` + `fonts/` | Rendered typeface comparison and verdicts by eye |
| `fonts-facts.md` | Cyrillic coverage, licenses, axes and features of the shortlist, with sources |
| `licensing-kits.md` | RonDesignLab identity and sales, copyright basics, Figma Community kits usable as structural checklists |
| `dataviz-design.md` | Chart design rules with numbers, chart component inventory, chart token needs |
| `motion-haptics.md` | Motion token schema and haptics registry across SwiftUI and web |
| `critic.md` | What the research missed and where surveys contradict each other |
| `verification.md` | Results of the adversarial fact-check pass per report, and what was corrected |
| `references.json` | The reference shots with credits and the `principles-only` policy, machine-readable for agents |

Reference images themselves are not stored in the repository (they are RonDesignLab's copyrighted portfolio); only the analysis is.
