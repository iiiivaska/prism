# Roadmap

Implementation plan for Prism after the blueprint. Each ticket is self-contained for `/execute-ticket`: it names its inputs, its acceptance check and the ADR it serves. Tickets inside a phase may run in parallel unless a dependency is listed. The system version stays `0.1.0` until Phase 3 ships the vertical slice; `0.2.0` closes Phase 5.

## Phase 4 — Breadth by layer (ADR-0012) (weeks)

Order inside each layer follows `docs/research/component-inventory.md` (most-used first). Every component ticket has the same acceptance: spec validated, both implementations at the spec version, snapshots paired, a11y block satisfied, parity green.

- **Primitives**: Icon, IconButton, Toggle, Checkbox, Radio, Slider, TextField, TextArea, Select, SegmentedControl, Chip, Badge, Avatar, Divider, ProgressBar, ProgressRing, Spinner, Skeleton, Tooltip.
- **Composites**: ListRow, StatCard, StatusPill, FormField, SearchField, PillTabs, Stepper, Timeline, Toast, Banner, Alert, Dialog, Sheet, Popover, Menu, TabBar, TopBar, Toolbar, EmptyState, Pagination; desktop: Sidebar, Table, CommandPalette, ContextMenu.
- **Data-viz wave 1** (ADR-0007, `dataviz-design.md` §5): HeroNumber, DeltaBadge, Sparkline first (they stress number formatting and Cyrillic compact names), then StatTile, RingGauge, LineChart/AreaChart with ReferenceLine and RangeBand, ChartContainer with table twin; `tools/viz-validate` for the series palette.
- **Patterns**: DashboardGrid, DetailScreen, AdaptiveShell as spec files plus gallery example screens.
- **watchOS subset**: the Tier 3 list from ADR-0010 with `ImageRenderer` snapshots.

## Verify before implementing

Open questions the research left; each is a checkbox in the ticket that touches it.

- **Style Dictionary native resolver** (issue #1590): when it ships, delete `tools/tokens/resolver.ts` (P1-3). Until then, duration objects and gradients with color objects need the custom transforms in P1-4.
- **Asset catalog high-contrast slot key**: confirm `"appearances": [{"appearance": "contrast", "value": "high"}]` by exporting a color set from Xcode 26 before generating `.xcassets` (P1-5).
- **Core Text on iOS/watchOS**: named-instance lookup and `kCTFontVariationAttribute` by numeric axis id were verified on macOS only; test on iOS 26 and watchOS 26 simulators (P3-1).
- **`Font.monospacedDigit()` on custom fonts**: expected to map to `tnum`; add the equal-width snapshot test (P3-3).
- **Bold Text × Light numerals**: verify `legibilityWeight` handling for the Signature font on OS 26 (P3-1).
- **Glass under Reduce Transparency**: community says `.glassEffect()` frosts automatically; Prism's `DSSurface` fallback makes it non-blocking, verify on device (P3-1).
- **macOS `NSHostingView` snapshots of glass**: may not render materials off-screen; if so macOS glass gets iOS-only visual coverage (P3-5).
- **React Aria Russian strings**: `ru-RU` is in the locale list; spot-check DatePicker and Table announcements (Phase 4 Table/DatePicker tickets).
- **Vitest 5 vs `@storybook/addon-vitest`** (peer `^3 || ^4` at 10.6): stay on Vitest 4 until the addon lists 5 (P0-2).
- **TypeScript 7 + tsdown `dts`**: verify declaration output before making TS 7 the workspace default (P0-2).
- **GitHub Packages provenance**: not documented; if attestations matter later, mirror public packages to npmjs with trusted publishing (P3-6).
- **`prefers-reduced-transparency`**: unsupported in Safari; gate web glass on `[data-ds-transparency=reduce]` set by `DSProvider` (P3-2).
- **Screenshot determinism for glass** (`backdrop-filter` under software rasterization): set `maxDiffPixelRatio` per story family after the first baselines (P3-4).
- **Phosphor maintenance** (no icon release since March 2024): budget for authoring missing glyphs in Phosphor style; keep Tabler as a documented secondary source (P2-2).
- **SF Symbols 8 / iOS 27**: CI rejects symbols newer than SF Symbols 7 until the floor moves (P2-2).
- **Chart series on vivid surfaces**: decide which gradient stop the contrast validator checks against (darkest, lightest, both) (data-viz wave 1).
- **Cyrillic compact number names** ("12,9 тыс.", "4,2 млн"): real-device width checks on both platforms (HeroNumber ticket).
- **Xcode 27 lane**: add when the GM ships; deployment floor stays 26 (P0-3).
- **Legal checkpoint** before any public release: Apple Design Resources reading for a cross-platform system, Untitled UI dual license, EU unregistered-design exposure (ADR-0015).
