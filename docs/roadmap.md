# Roadmap

Implementation plan for Prism after the blueprint. Each ticket is self-contained for `/execute-ticket`: it names its inputs, its acceptance check and the ADR it serves. Tickets inside a phase may run in parallel unless a dependency is listed. The system version stays `0.1.0` until Phase 3 ships the vertical slice; `0.2.0` closes Phase 5.

- **Bold Text × Light numerals**: verified 2026-09-15; custom fonts ignore `legibilityWeight` (ADR-0021 T8), so DSCore applies `boldWeight` itself (P3-1).
- **SwiftUI first-baseline shift with alignment guides** (ADR-0021 §8): verified 2026-09-16 on macOS 26 and the iOS 26.5 and watchOS 26.5 simulators. `.offset(y: −Δ)` plus `.alignmentGuide` overrides for `.firstTextBaseline` and `.lastTextBaseline` move the glyphs and both guides by Δ and leave the line box at `lineHeight × size`, so DSCore applies §8's correction and `Text.yaml` records no difference. Held by `DSTypographyTests` (`theFirstBaselineSitsAtTheCSSPosition`, `theLineBoxDoesNotChange`, `bothBaselineGuidesMoveWithTheGlyphs`, `aHungUnitSitsOnTheHerosBaseline`), which measure the rendered glyphs and a baseline-aligned marker against the CSS position within 0.5 pt (P3-1).
- **SwiftUI `Gradient.ColorSpace.perceptual` is OKLab** (ARCHITECTURE V14): verified 2026-09-16 on macOS 26 and the iOS 26.5 and watchOS 26.5 simulators, and the fallback is the one that ships. `.perceptual` *is* OKLab — a two-stop gradient rendered with `ImageRenderer` sits 0.7/255 from the OKLab samples while gamma-encoded sRGB is 5/255 and linear light 37/255 away, and `.device` is gamma-encoded sRGB to 0.3/255 — but an 8-bit render of the seeded gradients drifts up to 2.4/255 from those samples, above the 1/255 the P3-1 acceptance asks for. DSCore therefore takes the documented fallback: `DSGradient.stops` resamples each authored segment in OKLab (sixteen interior stops, kept in the stops' own color space) and draws them with `.device`, which measures within 1/255 on all three platforms. Held by `DSGradientTests` (`perceptualIsOKLab`, `deviceIsGammaEncodedSRGB`, `everySeededGradientInterpolatesInOKLab`). One divergence stays and is counted, not asserted away: the OKLab path between two dark saturated stops leaves the sRGB gamut, where an sRGB render clips and CSS gamut-maps (ARCHITECTURE §7.2) (P3-1).
- **Deterministic woff2 encoder** (ADR-0021 §11): choose an encoder whose output is byte-identical across runs; the fallback ships the TTF as `format("truetype")` (P1-8).
- **iPadOS pointing-device detection**: **still open, and shipped as unverified.** P3-1 wired the GameController `GCMouse` connect/disconnect mechanism ADR-0019 §5 names, but confirming that it reports the Magic Keyboard trackpad and a Bluetooth mouse needs an iPad on iPadOS 26, which the repository's CI and the owner's machine do not have; a simulator cannot answer it.
