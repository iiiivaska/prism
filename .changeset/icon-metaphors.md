Icon registry: three entries drew a different metaphor on each stack, the silent drift ADR-0013's registry exists to prevent. Each is rebound on the one side that contradicted its label and tags, so both stacks now draw the same thing. `action.share` draws Phosphor's `export` on the web (a tray with an arrow rising out of it, as Apple already drew it) instead of `share-network` (three joined nodes). `action.refresh` draws Phosphor's `arrow-clockwise` on the web (one circular arrow, as Apple already drew it) instead of `arrows-clockwise` (two chasing arrows). `action.locate` draws SF Symbols' crosshair with a centre dot on Apple, matching the web's `crosshair`, instead of the navigation arrow. SF Symbols draws that metaphor, so the entry stays an SF Symbol rather than a Phosphor image set. The symbol has no fill variant, so `filled` draws the outline crosshair on both stacks (Icon 2). `iconRegistry` changes `phosphor` and `component` for the two web entries, and the Tokens Studio icon list changes with it. No id, label, tag or type changes. The remaining entries were compared side by side on both stacks, in the outline and filled styles. Where their drawings still differ, they draw one metaphor in two ways, which ADR-0013 accepts. The exception was the filled style of entries whose SF Symbol has no fill variant. Icon 2 fixes that as a separate change. The duotone style has not been compared yet.
